关于这个站点

WHU Notice Hub 是一个非官方的本科生通知聚合站：定时抓取武汉大学官网、计算机学院、信息公开网等公开栏目， 自动去重、识别适用对象、抽取截止日期，并按重要度排序，方便快速了解"最近有什么和我有关的事"。

本站提供什么

只做标题 + 概览 + 原文链接：不转载正文、不存附件。这样既能快速浏览， 也不会因为复制内容产生版权或隐私问题；需要细节时点"查看原文"即可。

只收录本科生相关

系统会过滤掉主要面向研究生、教师、干部的通知（如博士招生、科研项目申报、干部任免、教职工会议等）， 保留推免、选课、考试、奖学金、竞赛、生活服务等与本科生相关的内容。

受限通知不展示

部分通知（多为含个人信息的公示名单）在校外访问时返回"暂无权限"，这类页面不会出现在站内， 以免用户点击后看到错误页；如需查阅，请登录校内门户。

技术说明

  • Python + FastAPI + SQLite，单机运行
  • 每 20 分钟增量抓取，按 URL 差集判断新增，原始页面保留 7 天快照
  • 提供 RSS 与 JSON API，方便二次开发
  • 站点为只读服务：无需登录，不收集访问者个人信息

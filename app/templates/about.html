修远Eker的Wave 是我个人自用的信息整理小站，不是学校官方站点。 官网、信息公开网、计算机学院等多个站点每天发布大量通知，真正和自己有关的那几条，往往会淹没在公示、会议通知和讲座预告里。 这个站点只做一件事：定时抓取公开栏目 → 过滤掉和自己无关的内容 → 按重要度分档 → 一键跳到原文，方便我自己查阅。

只做标题 + 概览 + 原文链接：不转载正文与附件，既能快速浏览，也避免版权与个人信息问题。 需要细节时点开原文即可，一切以官网为准。

站点做了什么

  • 聚合：把 6 个栏目的通知放到一个时间线里，支持按来源、分类、重要度、截止日期筛选
  • 过滤：自动剔除博士/硕士/教师/干部/科研/会议/讲座类内容，只保留自己关注的推免、选课、考试、奖助、竞赛、生活服务等
  • 去重：同一条通知发在多个栏目时，按「标题 + 发布日期」自动合并
  • 分档：重要度只分「重要 / 一般 / 参考」三档，不堆砌数字
  • 找得到：分类页、信源页、按月归档、站内搜索都可用

技术说明

  • Python + FastAPI + SQLite，单机运行，无前端框架依赖
  • 抓取基于各站点公开列表页（博达 CMS），只取标题与发布日期
  • 遇到访问频率限制（WAF 验证）时自动退避，不绕过、不硬闯
  • 数据存在 SQLite 里，按增量方式更新
  • 不登录、不采集访问者信息；页面只有只读内容与统计
